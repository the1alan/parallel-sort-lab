# Проверка проекта перед сдачей

## Фактически выполненные проверки

- `python3 -m compileall -q .` — проверка синтаксиса Python прошла.
- `xvfb-run -a python3 -m unittest discover -s tests -v` — 32 теста пройдены.
- GUI smoke-test выполнен в виртуальном X-сервере: окно приложения создалось, короткий эксперимент отработал, таблица результатов и графики отображались.
- Выполнены 75 реальных замеров сортировки; CSV содержит 25 агрегированных строк (медиана по трём повторам). Для каждого результата корректность проверялась сравнением с `sorted(input_data)`.
- CSV: `results/benchmark_results.csv`.
- Графики строятся из сохранённых измерений и находятся в `results/charts/`.

## Условия измерений

Замеры выполнены в контейнере Linux x86_64 с Python 3.13.5 и тремя доступными логическими CPU. Это не компьютер команды, поэтому значения времени следует трактовать как демонстрационные результаты конкретного стенда, а не как прогноз скорости на macOS.

Параллельный вариант в этих измерениях оказался существенно медленнее последовательного Merge Sort при 2 и 4 процессах. Это не ошибка измерений само по себе: запуск процессов и передача данных имеют заметные накладные расходы. Встроенный `sorted()` быстрее собственной реализации Merge Sort на данных этих тестов.

Полная расширенная матрица с многократным созданием пулов процессов не уложилась в лимит времени окружения, поэтому финальный CSV намеренно содержит ограниченную матрицу: случайные данные на трёх размерах (10 000, 50 000, 100 000) и сравнение типов входа на 50 000 элементов (случайные, отсортированные, обратный порядок). Недостающие измерения не синтезировались.

## Проверить на компьютере команды

Перед защитой рекомендуется запустить в активированном виртуальном окружении:

```bash
python -m unittest discover -s tests -v
python cli.py --sizes 10000 50000 100000 --types random --algorithms merge builtin parallel --workers 1 2 4 --repeats 3 --csv results/benchmark_mac.csv --charts results/charts_mac
python main.py
```

Сравните результаты на своём компьютере и при необходимости используйте локальные CSV и графики для окончательного устного анализа. Не утверждайте, что цифры из разных компьютеров полностью сопоставимы.
